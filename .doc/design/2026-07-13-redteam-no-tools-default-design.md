# redteam 无工具评审默认化（v1·已锁定）

## 0. 一句话

review 主评审与 refute **默认无工具**，证据由「变更集全景 pack + 预算降级梯子 + 二阶段补查」供给；
工具面从「对话式检索」收缩为「批量载入」，仅出现在二阶段补查与诊断档。

## 2. 目标形态

### 2.1 默认路径（变更集全景 ≤ 预算）

- **pack 0 壳 = 变更集全景**：自家 bundle 文件（diff+全文）优先 + 兄弟改动文件全文（今
  `REDTEAM_PACK_SCOPE=changeset` 转正为默认）。
- **主评审无工具**（今 `REDTEAM_NO_TOOLS` 转正），恒 1 轮/格。
- **refute 无工具 + 证据升档（裁决 F）**：refute 证据走文件内梯子——锚点文件全文 → 骨架 →
  ±60 快照（兜底=现状，行为不倒退）。refute 无工具化已有初证（B/S 臂 refute 全程无工具、判定
  方向与有工具臂一致）。
- **doc 模式同批翻转（裁决 H）**：doc 已是形态样板（单 cell + 文档全文入 prompt），needs
  机制零新增复用；不留对话工具特例。
- **散文修**：省略清单标题「已省略（可 read_files 定点读）」在无工具下自相矛盾 → 改「已省略
  （证据不足时二阶段可补）」；`NO_TOOLS_SYSTEM` 从实验壳转正。

### 2.2 预算与降级梯子（变更集全景 > 预算；每级先外围后自家、禁真空）

**预算函数（正确性而非优化，非开放问题）**：
`预算 = min(配置帽 256K 字节, per-model token limit − 壳/diff 开销 − 输出预留)`。
双层墙：字节帽是我们的策略、token limit 是硬墙（256K 字节 ≈ 70-90K token，128K 档模型已贴脸；
推理型模型输出预留更大）。per-model **常数查表**，不复活 S2-c 规划器。梯子在墙内分配得再精细，
整包撞墙全归零——此项归批 1。

| 级 | 动作 | 依据 |
|----|------|------|
| L1 | 兄弟文件：全文 → **改动 def 体（真 diff 锚）**——changeset scope 追加兄弟时必须传真 diff（空 diff 下 def 降级不可达且静默消失，cli.rs:385） | E7：兄弟改动=feature 其他块，价值密度最高；粒度 A/B 实测档 |
| L2 | 兄弟文件：改动 def 体 → **骨架**（签名地图，防幻觉引用） | |
| L3 | 自家文件：全文 → def 体，**保 hunk±N 兜底、禁真空**（def 锚定失败/非支持语言不允许空 0 壳） | T42+洞实证：真空=最弱产出（零产出/拼接引文） |
| L4 | 拆格：仅在**弱耦合缝**（文件级 import/引用图，regex 可建、SCIP 可选增强）；缝不弱**宁降不拆** | E7 范围错配：硬拆重开跨格失明 |

**降级排序 = 依赖距离**（爆炸半径残余岗位①）：离本格 diff 引用关系越远的兄弟越先降。
**降级空产出必入 omit**（禁真空的观测面；修现状 Rust 文件降级为空时的静默消失）。

**文件内梯子（单文件超预算的降分辨率，机械截断只兜底）**：
全文 → 骨架 → 点名区间 lines±N（needs 带行号时）→ 字节截断（char-boundary，最后兜底）。
适用于第一趟的巨型改动文件与二阶段的巨型 needs 文件。
**骨架语义更正（批 3 实施发现的设计内部矛盾，2026-07-13）**：原文「签名列表+改动 def 全文+
其余折叠」自败——骨架仅在改动 def 体已超预算时触发，含 def 全文的骨架必然更大。实际语义=
**签名行 + hunk 全部改动行 + 其余折叠**；且档位互斥（def 体部分入正文时不再叠加骨架）。

### 2.3 二阶段补查（证据不足的结构化出口）

- 输出契约加 `needs: [{path, lines?, reason}]`——模型**声明**缺证据，不是对话式工具调用。
  **cap 5 项**，超出截断+warning（防习惯性索要，观测优先于预防）；路径载入**复用 ToolExecutor
  既有安全不变量**（safe_join 拒绝绝对路径与 `..` + canonicalize 符号链接逃逸检查 + 读帽），
  不发明第二套路径处理——攻击面=read_files 现状，M16 一并审计。
- needs 非空 → 二阶段**重跑**该格（fresh prompt，非续聊）：**置换而非追加**——重走降级梯子，
  needs 文件置顶（优先级高于兄弟全景），依赖距离最远的兄弟反向让位/出局腾空间；第一趟
  findings 草稿（很小）随包带入，第二趟任务聚焦为验证/补全，全景完整性要求天然低于第一趟。
  恒 ≤2 趟/格。第二趟输出**整体替换**第一趟（修订版语义，不做 finding 级合并）；草稿以
  「确认或修订这些初步 findings」语义入第二趟 prompt——丢 finding 是模型显式决定而非机制缺陷。
  单个 needs 文件超预算 → 文件内梯子（§2.2）；带 lines 只载区间±上下文。触发条件=needs 非空
  即重跑，不做 conf 加权（触发率先实测再调）。
- **为什么重跑而非对话**：对话式工具在 input limit 墙边是死锁——历史不可丢（推理链在内）、
  新工具结果塞不进，截哪边都输；重跑把「下一轮进行不下去」（无解）转化为「第二趟预算重分配」
  （有解）。这是砍工具的又一结构性论据（补 F1/F4）。
- 常驻 `batch_file_read` 工具只作 A/B 对照臂，不是默认（F1 反对常驻工具）。
- 预期：小变更集触发率≈0（B 臂无此出口质量已未降），保险价值在大仓/降级档。

### 2.4 配置面（内置命令优先）

- config `[review] tools = "off" | "two-stage"(默认候选) | "on"`；`--tools` flag 覆盖。
- **off 档语义（批 1 doc smoke 审出的 gap，2026-07-13 补）**：off=纯无工具单趟，needs 声明仅用于降 conf/披露、**永不触发二阶段**；two-stage=needs 非空触发补跑。批 1 内两档行为等价（needs 未实现）。
- `on` = 现行为，保留作诊断/对照档。`--help` 同步（裸终端唯一在场文档）。

## 3. 分批实施（建议序）

- **批 0（前置件）：T43 refute parse 韧性（裁决 G，三层）**——①前缀嗅探（strip 包装后头部
  REFUTED/UPHELD，复用 classify_refute 前缀语义；不做全文正则）②嗅探不明才重试一次③兜底保
  原 conf + warning（宁假 reject——假 approve 是 r1 20260703 老事故方向）。refute 是无工具世界
  唯一质量闸门，先修再翻。
- **批 1：默认翻转（裁决 A）**——changeset scope（含 L1 真 diff 修正）+ no tools 默认 `two-stage`、
  per-model 预算函数（§2.2）、省略散文改写、config/flag/help。**验收三臂**（均免费级、同语料）：
  ①异语料 smoke（中型 Rust 仓真 PR 一跑）②单格全审 A/B 臂（裁决 B，~56K/跑）③纯 0 壳减法臂
  （裁决 E 第一层，需小仪器如 `REDTEAM_PACK_SHELLS=0`）。
- **批 2：二阶段补查 + 证据升档（裁决 C/F/H）**——needs 契约 + 置换式重跑 + 文件内梯子 +
  refute 证据升档 + doc 模式同批翻转；验收含 doc smoke + refute note 人工抽查；观测 needs
  触发率（含 SCIP 判决树的 needs 指标）。
- **批 3：降级梯子**——L1-L3 排序实现（依赖距离）+ 空产出入 omit；L4 拆缝可后置（小仓语料
  触发不了）。
- **批 4（数据判决后）：fan-out 收缩 + lens 去实体化收尾**——单格 A/B 胜出才收缩；杂交备选=
  焦点 prompt 变体（lens 去实体化后不需要 lens 实体）；lens 报告字段删除待消费面查证（数据契约）。

## 4. 验证（裁决 A：验证门降级为回归监控，不再前置于翻默认）

前置进批 1 验收的最低配：异语料 smoke 一跑。翻转后的回归监控项：①多模型复验（gpt-5.5 紧尺 +
MiniMax）②大变更集语料（**必须触发降级梯子路径**）③二阶段有效性（F5 的 17% 读需求价值判定）。
refute 无工具化已初证（§2.1）。成本纪律照旧：方向性单模型 DeepSeek、下门决策才 3 模型×N。
